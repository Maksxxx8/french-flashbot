# 🇫🇷 Flashbot — Французский для Парижа (A1 → B1)

Telegram-бот для изучения французских слов с упором на **реальные ситуации в Париже**: аэропорт, метро, кафе, отель, улицы, магазины.

- 🤖 **LLM:** Google Gemini API (генерирует слова, примеры, проверяет ответы)
- 🔊 **Озвучка:** edge-tts — нейросетевые голоса Microsoft (голос `fr-FR-DeniseNeural`)
- 🧠 **Алгоритм запоминания:** SM-2 (Spaced Repetition — интервальное повторение)
- 📱 **Интерфейс:** Telegram

---

## 📦 Где хранятся данные

Все данные хранятся в папке `resources/` в CSV-файлах — никакой базы данных не нужно.

| Файл | Что хранится |
|------|-------------|
| `resources/words_db.csv` | Все слова (id, слово, язык, значение) |
| `resources/decks_db.csv` | Колоды слов (привязаны к пользователю) |
| `resources/deck_word.csv` | Связь слово ↔ колода |
| `resources/words_progress_db.csv` | Прогресс каждого слова (SM-2: интервал, повторения, дата следующего повтора) |
| `resources/user_config.json` | Настройки пользователя (язык, уровень, расписание) |

**Важно:** слова генерируются автоматически Gemini при первом запросе — папку `resources/` можно трогать, но не удалять.

## 🚀 Быстрый старт

### 1. Создать Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot` и следуй инструкциям
3. Скопируй **Bot Token**
3. Добавь команды боту (`/mybots` → Edit Bot → Edit Commands):
   ```
   start - Начать и узнать свой chat_id
   next_new - Новое слово
   next_test - Тест слова
   add_word - Добавить слово вручную
   ```

### 2. Получить Gemini API ключ

1. Зайди на [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Создай API ключ (бесплатно, лимит: 15 запросов/мин)

### 3. Telegram chat_id (Автоматически!)

Вам **не нужно вручную вписывать chat_id**!
Бот использует профиль `"default"` в `resources/user_config.json`. Как только вы отправите боту команду `/start`, он:
- Покажет ваш `chat_id`
- Автоматически зарегистрирует вас с профилем изучения французского
- Сохранит ваши настройки

### 4. Установить зависимости

```bash
cd /home/maks/Документы/flashbot-main
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 5. Настроить переменные окружения

```bash
cp .env.example .env
# Открой .env и заполни:
# BOT_TOKEN_ENG=твой_токен_бота
# GEMINI_API_KEY=твой_ключ_gemini
```

### 6. Запустить бота


```bash
source venv/bin/activate
python main.py
```

Бот запустится и будет ждать сообщений. Логи выводятся в терминал.

## 💬 Как пользоваться

### Команды

| Команда | Что делает |
|---------|-----------|
| `/next_new` | Показать новое слово с карточкой |
| `/next_test` | Тест: перевести фразу на французский |
| `/add_word` | Добавить своё слово вручную |

### Кнопки на карточке

| Кнопка | Действие |
|--------|---------|
| **Еще** | Следующее слово |
| **Произнеси** | Прослушать произношение (edge-tts) |
| **Забыть** | Убрать слово из своей колоды |
| **Подсказка** | Подсказка (снижает оценку) |
| **Правильный ответ** | Показать ответ |
| **Аудио ответа** | Прослушать правильный ответ |

## 🧠 Алгоритм SM-2 (как работает повторение)

Бот использует **Spaced Repetition (SM-2)** — научно доказанный метод запоминания:

| Попытка | Следующий повтор |
|---------|-----------------|
| 1-я (новое) | Через 1 день |
| 2-я | Через 6 дней |
| 3-я | Через ~2 недели |
| 4-я | Через ~1 месяц |
| Далее | Растёт с каждым успехом |

- ✅ Ответил правильно → интервал увеличивается
- ❌ Ошибка → слово сбрасывается, повторяется чаще
- 📌 Слово не повторяется чаще чем нужно — мозг запоминает эффективно

## 🔧 Тематики слов (автогенерация)

Gemini генерирует слова по 7 тематикам поездки в Париж:
1. ✈️ Аэропорт (регистрация, baggage claim, паспортный контроль)
2. 🚇 Транспорт (метро, такси, автобус, РЕР)
3. 🏨 Заселение (отель, номер, ресепшн)
4. ☕ Кафе и рестораны (меню, заказ, счёт)
5. 🗺️ Ориентирование (адрес, направления, карта)
6. 🛍️ Шоппинг (цена, размер, касса)
7. 💬 Общение (приветствия, вежливые фразы)

# 🇫🇷 Flashbot — Французский для Парижа (A1 → A2)

Умный Telegram-бот для изучения французского языка с упором на **реальные ситуации в Париже**: аэропорт, метро, отель, кафе, заказ еды, счёт, билеты, ориентирование на улицах и магазины.

- 🤖 **LLM:** Google Gemini API (генерация карточек, примеров, контекстное тестирование и оценка ответов).
- ⚡ **Сверхэкономичность:** по умолчанию используется модель `gemini-3.5-flash-lite` ($0.075 за 1M токенов, мгновенный ответ, без скрытых токенов размышлений) с автоматическим откатом к `gemini-3.6-flash`.
- 🔊 **Озвучка:** Microsoft edge-tts (нейросетевой голос `fr-FR-DeniseNeural`) — голосовые сообщения отправляются сразу вместе с карточкой слова и воспроизводятся в хронологическом порядке.
- 📦 **Предгенерированный буфер:** бот держит в запасе от 5 до 15 готовых слов с предгенерированным аудио, обеспечивая моментальную выдачу карточек без ожидания ответа API.
- 🧠 **Интервальное повторение:** проверенный алгоритм SM-2 (Spaced Repetition).
- 🎯 **Строгий уровень A1–A2:** тестирование строится исключительно на изученных пользователем словах, без сложной академической грамматики и редкой лексики.

## 🚀 Быстрый старт

### 1. Создать Telegram-бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь `/newbot` и следуй подсказкам.
3. Скопируй полученный **Bot Token**.

### 2. Получить Gemini API ключ
1. Зайди на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Создай бесплатный API-ключ.

### 3. Клонировать репозиторий и установить зависимости
```bash
git clone https://github.com/Maksxxx8/french-flashbot.git
cd french-flashbot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Настроить переменные окружения
Создай файл `.env` на основе примера:
```bash
cp .env.example .env
nano .env
```
Заполни значения:
```env
# Токен Telegram-бота от @BotFather
BOT_TOKEN_ENG=твой_токен_бота

# API-ключ Google AI Studio
GEMINI_API_KEY=твой_ключ_gemini

# Модели Gemini (gemini-3.5-flash-lite рекомендуется для минимального расхода токенов)
MODEL_BASE=gemini-3.5-flash-lite
MODEL_SUBSTITUTE=gemini-3.5-flash-lite
```

### 5. Запуск бота
```bash
source venv/bin/activate
python main.py
```
При отправке команды `/start` бот автоматически зарегистрирует вас и создаст персональную колоду для изучения. Меню команд `[/]` в Telegram также зарегистрируется автоматически.

## 💬 Все команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота, авторегистрация и приветствие |
| `/help` | Подробная справка по всем функциям, командам, кнопкам и статусу уведомлений |
| `/next_new` | Показать следующее новое слово из буфера (сразу с голосовым сообщением) |
| `/next_test` | Запустить тест (проверяются только ранее изученные слова) |
| `/stop`, `/notifications_off`, `/unsubscribe` | Отключить авторассылку по расписанию (учиться только вручную в своём темпе) |
| `/notifications_on`, `/subscribe` | Включить авторассылку по расписанию (5 раз в день) |
| `/reset` | Полный сброс истории и прогресса (начать обучение заново с 0) |
| `/add_word <слово>` | Добавить собственное слово в базу для изучения |

## 🎮 Кнопки в сообщениях

### В карточке нового слова (`/next_new`)
* **Next** — отметить слово изученным, запланировать его повторение по алгоритму SM-2 и перейти к следующему слову.

### В режиме тестирования предложений (`/next_test`)
* **Easier** / **Harder** — переключение сложности предложения (уровни 1–5).
* **Hint** — показать подсказку (первая буква целевого французского слова).
* **Correct answer** — показать правильный ответ.
* **Answer audio** — прослушать правильное произношение фразы.

### В режиме флэшкарт (перевод слова в контексте)
* **Правильный ответ** — показать правильное слово и пример.
* **Еще** — перейти к следующему упражнению.

## 🎯 Система тестирования и градация сложности

В тестах бот использует **только те слова, которые ученик уже проходил** (`num_reps > 0`), подбирая для них естественный парижский контекст:

| Уровень сложности | Описание предложения | Пример |
|---|---|---|
| **1 (минимальный)** | Сверхпростая короткая фраза (2–3 слова в Présent) | *Voici le billet.* («Вот билет.») |
| **2 (базовый)** | Короткая фраза (3–4 слова) | *Où est le billet ?* («Где билет?») |
| **3 (средний)** | Простое предложение A1 (4–5 слов) | *Je voudrais un billet.* («Я хотел бы билет.») |
| **4 (продвинутый A1)** | Расширенное предложение (5–6 слов) | *Je cherche le billet de métro.* («Я ищу билет на метро.») |
| **5 (разговорный)** | Живая фраза туриста (6–8 слов) | *Je voudrais un billet pour la gare.* («Я хотел бы билет на вокзал.») |

### Логика оценивания (Fast-path и доброжелательность к A1):
* **Точный ответ** (например, `L'addition` для `l'addition`): бот мгновенно ставит **5 из 5** без задержек и без расхода токенов на вызов LLM.
* **Ответ без артикля** (`addition` вместо `l'addition`): бот ставит **5 из 5** и дружелюбно напоминает форму с артиклем.
* **Опечатки / другие формулировки:** LLM оценивает общий смысл, не занижая оценку строго за мелкие неточности.

## 📦 Где хранятся данные

Все данные хранятся локально в директории `resources/`:
* `resources/words_db.csv` — база слов, переводов, примеров и путей к кэшированному аудио.
* `resources/decks_db.csv` — колоды пользователей.
* `resources/deck_word.csv` — привязка слов к колодам.
* `resources/words_progress_db.csv` — история повторений SM-2 (интервалы, даты следующего показа).
* `resources/user_config.json` — настройки пользователей (язык интерфейса, статус уведомлений, расписание).
* `resources/templates/russian/french/` — шаблоны запросов к Gemini и шаблоны сообщений Telegram.

## 🛠️ Развертывание на Linux-сервере как служба systemd

Чтобы бот работал непрерывно в фоне и автоматически перезапускался при перезагрузке сервера:

### 1. Создать каталог для логов
```bash
mkdir -p /var/log/flashbot
chown -R root:root /var/log/flashbot
```

### 2. Создать unit-файл службы
Создай файл `/etc/systemd/system/flashbot.service`:
```ini
[Unit]
Description=French Flashbot Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/french-flashbot
ExecStart=/root/french-flashbot/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=append:/var/log/flashbot/bot.log
StandardError=append:/var/log/flashbot/bot.log

[Install]
WantedBy=multi-user.target
```
*(Примечание: укажи свой реальный путь к проекту и виртуальному окружению, если он отличается).*

### 3. Запустить и включить автозагрузку
```bash
systemctl daemon-reload
systemctl enable flashbot
systemctl start flashbot
```

### 4. Полезные команды управления
* Статус службы: `systemctl status flashbot`
* Перезапуск после обновлений: `systemctl restart flashbot`
* Остановка службы: `systemctl stop flashbot`
* Просмотр логов в реальном времени: `tail -f /var/log/flashbot/bot.log` или `journalctl -u flashbot -f`
